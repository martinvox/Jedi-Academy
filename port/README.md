# Jedi Academy → Godot 4 port

Overall plan: [`docs/GODOT_PORT_PLAN.md`](../docs/GODOT_PORT_PLAN.md). Progress and next steps: [`STATUS.md`](STATUS.md).

The port reads game data **directly from your own retail copy** (the `.pk3`
files in `GameData/base`). No game assets are stored in this repository.

## What you need

| Tool | Why | Get it |
|---|---|---|
| **Godot 4.7.x** (standard build, not .NET; tested with 4.7.1) | runs the port | https://godotengine.org/download |
| **Jedi Academy** (Steam/GOG/CD) | the game data | your install, e.g. `C:/Program Files (x86)/Steam/steamapps/common/Jedi Academy/GameData` |
| Python 3 (optional) | regenerates the test fixture | https://python.org |
| Git | clone the repo | https://git-scm.com |

Nothing has to be compiled. The port is GDScript only for now.

## Run the map viewer

```sh
git clone https://github.com/martinvox/Jedi-Academy.git
cd Jedi-Academy
git checkout claude/exciting-mendel-ieutjw
```

1. Open Godot, click **Import**, select `port/godot/project.godot`.
2. Press **F5** (Run Project).
3. In the panel, paste your `GameData` folder path (the folder that contains
   `base`) or click **Browse...**, then **Load**.
4. Double-click a map (`mp/ffa_bespin`, `t1_sour`, ...).

You spawn at the map's start point and walk with the ported Jedi Academy movement:
**WASD** move, **Space** jump, **C** crouch, **Shift** walk, mouse look,
**T** first/third person, **V** noclip, **F** free-fly camera (Space/C up/down, Shift fast),
**Esc** releases the mouse, **Tab** returns to the map list.

From a terminal (the path is remembered after the first run):

```sh
godot --path port/godot -- --gamedata="C:/.../Jedi Academy/GameData" --map=mp/ffa_bespin
```

Extra options after `--`:

- `--game=<moddir>` mounts a mod folder over `base`.
- `--view="x y z pitch yaw"` places the camera (in Quake coordinates, as shown by `/viewpos` in the original game).
- `--screenshot=out.png` renders the map, saves a screenshot and quits.
- `--quit-after-load` loads the map, prints stats and missing textures, then quits.

## Run the tests

```sh
godot --headless --path port/godot --import            # first time only
godot --headless --path port/godot -s res://tests/run_tests.gd
```

The tests use a small synthetic install in `port/godot/tests/fixtures/gamedata`,
which is generated by `python3 port/tools/make_test_map.py port/godot/tests/fixtures/gamedata`.
`make_test_map.py <dir> --stress 10000` builds a large map for timing.

## Layout

```
port/godot/src/fs/ja_vfs.gd                 pk3/loose-file VFS, original search order
port/godot/src/formats/rbsp.gd              Raven BSP v1 parser
port/godot/src/formats/q3_shader_library.gd .shader script parser
port/godot/src/world/ja_map_builder.gd      BSP -> meshes, collision, entities
port/godot/src/world/ja_materials.gd        shader defs -> Godot materials
port/godot/src/world/bezier_patch.gd        curved surface tessellation
port/godot/src/world/ja_environment.gd      skybox / environment
port/godot/src/world/ja_coords.gd           Quake <-> Godot coordinate conversion
port/godot/src/physics/ja_collision_world.gd box traces vs brushes (port of cm_trace.cpp)
port/godot/src/physics/ja_pmove.gd           player movement (port of bg_pmove.cpp / bg_slidemove.cpp)
port/godot/src/player/ja_player.gd           input -> usercmd, fixed tick, 1st/3rd person camera
port/godot/src/viewer/                      map viewer + free-fly camera
port/tools/make_test_map.py                 synthetic test data generator
port/tools/autosave.sh                      periodic commit+push while working
```

Conventions: 1 Quake unit = 0.0254 m. Godot = (q.x, q.z, -q.y). Physics layers:
1 solid, 2 player clip, 3 monster clip, 4 shot clip, 5 ladder.
